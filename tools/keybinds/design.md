# Пресет управления All in One

Раскладка сохраняет базовое управление Minecraft 1.16.5. F6 открывает квесты FTB Quests, M открывает карту FTB Chunks, F8 открывает список путевых точек Xaero, B создаёт точку. G оставлена за меню Building Gadgets, O открывает Curios, 0 открывает книгу Ars Nouveau. Left Alt открывает меню инструмента Create, Delete открывает меню набора инструментов. Переназначения задаёт `layout.json`, остальные клавиши берутся из снимка. Ранее отключённые действия сохраняются отключёнными, кроме добавленной клавиши квестбука.

## Источник и проверка

В `registered-keys.json` сохранены только строки назначений из `options.txt` предыдущего изолированного запуска All in One на Forge 36.2.34. Все 164 строки совпали с сохранёнными назначениями действующей установки. SHA-256 снимка и 113 игровых JAR закреплены в той же записи. JAR сверены с опубликованным манифестом указанной там ревизии.

Проверка использует симметричное сравнение клавиш с учётом модификаторов Forge 36.2.34. Контексты Minecraft сверены с `GameSettings.setForgeKeybindProperties`, JEI с `mezz.jei.config.KeyBindings`, Refined Storage с `RSKeyBindings`, Mekanism с `MekanismKeyHandler`, Chisels & Bits с `KeyBindingManager` и `HoldsSpecificItemInHandKeyConflictContext.isActive`. Для действий с неподтверждённым контекстом используется консервативное пересечение со всеми контекстами. Для Chisels & Bits проверка допускает пересечение с другими игровыми действиями в модели, поскольку инструменты могут находиться в обеих руках, и разделяет их с экранными действиями JEI. Одиночные Page Up/Down в JEI меняют страницы, с Shift меняют категории. В активном мире те же клавиши меняют режимы экипировки Mekanism.

Два назначения FancyMenu с пробелом в конце зарегистрированного имени остаются в личных настройках. В указанной версии обработчик `de.keksuccino.fancymenu.keybinding.Keybinding` требует Ctrl и Alt одновременно. Пробел является частью имени, которое не проходит проверку формата пресета лаунчера. Поэтому файл содержит 162 записи. Проверка резервирует основы сочетаний FancyMenu. Одиночная R в JEI разрешена только без модификаторов в GUI, а штатная C в творческом режиме требует дополнительную клавишу слота. В Refined Storage клавиша деления на цифровом блоке фокусирует поиск, с Ctrl очищает сетку крафта. Проверка не покрывает пользовательские скрипты ввода, назначенные вручную сочетания операционной системы и скрытые обработчики сторонних модов.

После обновления JAR проверьте новые регистрации и контексты, обновите снимок и запустите:

```sh
python -B tools/keybinds/build_preset.py
python -B tools/keybinds/check_preset.py
```

Эта приёмка выполнена вне игры. Сохранённые регистрации, байткод и проверка файла пресета не заменяют проверку нажатий в клиенте. Minecraft для этой задачи не запускается.
