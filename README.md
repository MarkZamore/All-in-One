# All in One [Modded One Block]

Подготовка сборки 1.5.4b для LANMinecraft. [Авторский клиентский выпуск](https://www.curseforge.com/minecraft/modpacks/all-in-one-modded-one-block/files/4735035)

`tools/upstream-client-lock.json` фиксирует SHA256 и размер оригинального ZIP, ссылки на официальный источник, записи зависимостей и SHA256 файлов внутри авторских overrides. Minecraft и загрузчик взяты из оригинального манифеста. Java в `portable-pack.json` соответствует выбору текущего лаунчера для этой версии Minecraft и проверяется при запуске.

## Восстановление авторского клиента

Закреплённый авторский клиент CurseForge использует project ID 439293 и file ID 4735035.
Для подготовки текущего кандидата из корня LANMinecraft запустите:

```powershell
python -B LocalSources/All-in-One/tools/skin-agent/author_stage.py --launcher-source . --stage $stage
```

`tools/overlay.json` сохраняет политику открытия мира через Steam. Для нового авторского выпуска снимите отдельную квитанцию через `prepare.py --client-only` и проверьте её командой `release_overlay.py review-update`. При изменении защищённого входа пересмотрите рецепт и закрепите новые точные байты. После нативной проверки сохраните полный `tools/upstream-lock.json` и добавьте `--manifest <путь>` к команде `author_stage.py`, чтобы сверить готовый манифест, включая адаптер скинов.

## Русский квестбук

FTB Quests использует штатные языковые подстановки в 17 главах и в таблице наград «Семена». KubeJS подаёт словари в Minecraft, поэтому русский текст выбирается настройкой языка игры, а для остальных языков используется авторский английский. Квестовые идентификаторы, условия, награды и прогресс сохраняются.

Ручной перевод хранится в `tools/questbook-localization/ru` и привязан к исходным строкам. Для проверки воспроизводимости запустите `python -B tools/questbook-localization/build.py <авторский ZIP> --check` из репозитория сборки. Запуск без `--check` пересобирает SNBT, словари и рецепт.

При любом авторском обновлении сначала выполните обычный `review-update`, затем проверьте весь инвентарь квестов генератором на новом ZIP с обновлённым авторским lock. Существующие переводы сохраняются для точных совпадений. Для новых и изменившихся фраз дополните словари по сообщению генератора, а при удалении глав уберите их файлы из рецепта и ownership. Проверьте сборку на обоих языках перед публикацией. Установленные клиенты получают файлы квестбука и оба словаря как управляемые файлы сборки.

Для выпуска только перевода поверх совместимого публичного манифеста используйте `tools/questbook-localization/stage_update.py <авторский ZIP> <выход> --base-sha256 <SHA256 манифеста>`. Инструмент пересобирает архивы конфигурации, KubeJS и ownership, проверяет их исходные байты и сохраняет опубликованные игровые зависимости. Остальные изменения готовятся по обычному процессу релиза.

## Публикация

Для Java 8 сборка поставляет адаптер скинов в `lanminecraft/legacy-skins.jar`. Для сетевого профиля он ищет точный UUID в переданном лаунчером реестре идентичности Steam и использует UUID владельца только для поиска скина. UUID игрового профиля сохраняется. Адаптер принимает локальный URL только для зарегистрированного скина. `tools/skin-agent/Build.ps1` собирает JAR с JDK 25.0.2 и исходниками LANMinecraft из `tools/skin-agent/lock.json`. `tools/skin-agent/stage_update.py` собирает адресное обновление из зафиксированного публичного манифеста и JAR с проверенной контрольной суммой.

Обработчик чата обращается к штатному разрешению Minecraft первым. Если оно отсутствует, окно чата разрешается для локального профиля LANMinecraft с включённым чатом и текущим игровым подключением к приватному миру Steam. Обработчик сверяет метку сессии лаунчера и игровой порт действующего Steam-моста. Сервер по-прежнему решает, принимать ли сообщения и команды. Для онлайн-профиля, прямого подключения и выделенного сервера действует обычная проверка Minecraft.

При получении сообщения хостом его клиент сверяет отправителя с участниками действующего приватного Steam-сеанса. Для подтверждённого участника, включая его UUID лаунчера, клиент применяет штатный фильтр блокировок игроков. Обычные сервера и другие отправители используют прежнюю проверку чата.

`tools/skin-agent/Verify-SteamChat.ps1` проверяет единственное место вызова в патченном Forge 36.2.34 и границы разрешения на Java 8. Сценарий использует подставной профиль Steam. Приёмка выпуска требует также открыть чат штатной клавишей из подключённого клиентского профиля и увидеть отправленное сообщение на хосте.

В профиле LANMinecraft адаптер открывает штатный список серверов со Steam. Флаг отключения мультиплеера при запуске и проверка доступности Realms сохраняются. Simple RPC получает число игроков из текущего подключения. Дополнительный запрос статуса выполняется только для максимального числа игроков на обычных серверах. На Steam подключение для такого запроса задерживало отрисовку у гостя.

Проверка VerifyBytecode.java использует закреплённые классы Forge 36.2.34 и Simple RPC 3.2.2. Она проверяет изменяемые инструкции и запускает обработчики в Java 8 с тестовыми объектами. Verify-Menu.ps1 открывает список серверов кнопкой FancyMenu в установленной игре и проверяет наличие расширения Steam. Задержку у сетевого гостя проверяют с двумя аккаунтами.

`tools/skin-agent/Verify-SteamSkins.ps1` сравнивает опубликованный и новый агенты на Java 8 с Authlib 2.1.28 из Minecraft 1.16.5. Проверка читает PNG обоих тестовых игроков через локальный HTTP, проверяет модель Slim, смену реестра, отказ при конфликте UUID и сохранение штатной проверки подписи.
